# 校园论坛小程序

面向高校校园生活的微信小程序项目，集校园社区、课程表、跑腿和校园服务于一体。仓库包含小程序前端、Node.js 服务端，以及教务系统对接工具。

> **项目主页说明：** 本仓库主体是校园综合服务小程序，不是播报机器人。微信群播报只是其中一个辅助功能；独立的 Windows 播报客户端及其使用说明见 [`broadcast-bot/`](./broadcast-bot/)。

## 项目功能

- **校园社区**：浏览、发布和分享帖子，参与评论、互动与私信。
- **课程表与教务服务**：管理课程表，并支持对接教务系统同步相关信息。
- **校园跑腿**：发布和承接跑腿订单，查看订单进度并与参与者沟通。
- **校园生活服务**：提供校园服务入口，以及评价、活动、社团等功能。
- **配套能力**：个人资料、消息通知、后台管理，以及可选的微信群内容播报。

具体功能与架构以[项目文档索引](./docs/README_文档索引.md)和各专题文档为准。

## 技术组成

| 部分 | 技术 |
| --- | --- |
| 微信小程序 | 原生小程序框架（WXML、WXSS、JavaScript） |
| 服务端 | Node.js、Express |
| 数据与实时通信 | MySQL、Redis、WebSocket |
| 教务系统对接 | Node.js、axios、cheerio、tesseract.js |

## 本地开发

### 小程序

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择“导入项目”，将本仓库根目录作为项目目录。
3. 使用你有权限使用的小程序 AppID，并按需配置开发环境的服务端 API 地址。
4. 编译运行并在开发者工具中调试。

### 服务端

服务端需要 Node.js 18 或更高版本，以及按项目配置准备的数据库和相关服务。

1. 进入 `server/`，安装依赖：`npm install`。
2. 根据 `server/.env.example` 创建本地 `server/.env`，填写自己的开发环境配置。
3. 启动服务：`npm start`。

请勿将真实密钥、账号凭据或生产环境配置提交到仓库。完整架构、部署和测试说明见[文档索引](./docs/README_文档索引.md)。
