## 咨询：把内容自动推到微信群的可行路径（未动代码）

### ⚠️ 先记纠错（第一版结论有错，已推翻）
- **错误结论**：第一版说「企业微信群机器人 Webhook 可以加到外部群/客户群」——**这是错的**。
- **官方原文依据**（企业微信帮助中心 `open.work.weixin.qq.com/help2/pc/14931`）：
  - 「目前**内部群聊**支持消息推送，**外部群暂不支持**。」
  - 常见问题：「**外部群聊暂不支持添加「消息推送」**，可检查群聊是否为外部群。」
  - 支持添加的群聊只有三类：内部群聊（含全员群）、自建应用创建的内部群聊、jssdk 接口创建的内部群聊 —— **全是内部群**。
  - v4.1.41 起「群机器人」已更名为「**消息推送**」，在群里按旧名「群机器人」找会找不到（用旧名做实测会得到假阴性）。
  - 官方 API 文档 91770 也仅覆盖内部群。
- 结论：**群机器人/消息推送 Webhook 无法触达含微信用户的外部群**，是官方产品层面的限制，不是配置问题。

### 唯一合规的「外部群」触达路径
- `POST /cgi-bin/externalcontact/add_msg_template`，`chat_type="group"` + `chat_id_list`（单次最多 2000 个客户群）+ `sender`（必填）。**注意接口名是 `add_msg_template`，不是 `add_appchat_msg_template`**。
- **调用接口不会直接发送**，群主（企微员工）在企微收到服务通知后**点「发送」才发出** —— 官方防骚扰设计，**无法静默全自动**。
- 频率：每位客户/每个客户群每月最多接收条数 = 当月天数，可在「群发助手-设置群发规则」改为「每周 7 条」或「每天 1 条」。
- 支持 text/image/link/miniprogram/video/file，最多 9 个附件；`miniprogram` 的 appid **必须是已关联到该企业的小程序**。
- 前提：企业需「客户联系」权限，自建应用要配置进「可调用应用」列表。
- 其他官方边界：企微应用消息只能发企微成员（单聊）；微信客服只能人工接待；欢迎语/群活码是固定文案。

### 最终选型结论
- 要「官方 + 全自动」进含微信用户的群 → **不存在**。
- 官方合规半自动 → `add_msg_template` 客户群群发，由群主每天点一次确认。
- 全自动只能走非官方：iPad 协议（企微，可云端部署，SCRM 主流）> PC Hook（依赖客户端版本）> UI 自动化 / RPA。
- 非官方风控底线：外部群单号 ≤2 条/分钟、用实名老号、不做营销式群发。
- 替代思路（零风控）：小程序订阅消息逐人推 + 分享卡片由人工转发。

## 参考实现辨认：「信院论坛」群播报（截图分析，未定论）
- 现象：微信群（184 人）里一个号连发论坛帖子标题 + 链接，每帖后挂固定两条尾巴（驾校广告 `#小程序://在校生/...` + 投稿入口 `mp://AGPYj1UEavue9NF`）→ **内容侧是程序模板拼装**。
- 该号在微信侧显示为「**论坛广播@无妄个**」。企微帮助文档 17406 原文有「在微信侧群聊里或企业微信外部群查看的成员姓名@简称」→ 这个格式**高度提示是企微成员号**（但个人微信昵称含 @ 也会长这样，非铁证）。
- `mp://xxxxx` = **微信小程序短链**（官方 Short Link 接口生成，只能在微信内点击拉起小程序）；`#小程序://名称/路径` = 小程序分享链接文本。两者都是官方合规能力，只要自家小程序 access_token。
- 但「送进群」这步：企微客户群无静默发送接口 → 只可能是 (a) `add_msg_template` 群发任务 + 群主点确认（半自动，消息以该成员身份出现在群里，正好是「姓名@企业简称」），或 (b) 非官方自动化（iPad 协议 / Hook / UI 自动化）。**截图无法唯一区分**。
- 决定性自查：点该号头像看资料页有无企业信息 / 群设置看群主是否企微号 / 问运营「每条是否有人在企微点发送」。
