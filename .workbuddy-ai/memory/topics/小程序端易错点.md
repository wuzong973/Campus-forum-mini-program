# 小程序端易错点（样式 / 图标 / 测试 / 杂项）

> 从 `MEMORY.md` 拆出（2026-10-06）。低事故区，改小程序端时读取。

- **`focus="{{x}}"` 是受控属性**，变 `true` 就聚焦拉起键盘 —— 打开只读面板（如首页评论面板）不要置 `true`。**`adjust-position="{{false}}"` 必须自己处理键盘高度**：fixed bottom 元素须绑 `bindkeyboardheightchange`（`pages/post-detail/index.wxml`）。**两个评论入口语义不同**：首页 `commentMode="sheet"`（原地开面板），其余 `"detail"`（跳详情 + `&comment=1`）。`wx.setClipboardData` 成功后微信自弹「已复制」，**不要再 showToast**。
- **矢量图标统一层 `styles/ui-icons.wxss`**：小程序 `<image>` 不能显示 `.svg`，**必须 `background-image: url("data:image/svg+xml,...")`**（`#` 转义 `%23`）。优先级 `uiIcon → fontIcon → image`；**`iconPath`（后台图片）高于 `uiIcon`**，判定必须写 `iconPath ? '' : (def.uiIcon || '')`，**首页宫格与个人中心两处都要**。
- **⚠ 内联 SVG 必须是「`<svg>` 直接包 `<path>`」的扁平结构，禁用 `<g>` / `transform`**（2026-10-06 实机踩坑）—— 微信 WXSS 的 `background-image` 对内联 SVG 解析不如浏览器宽容，`<g>` / `transform=` 会让**整张图静默渲染失败**（格子空白、**控制台无任何报错**），极易误判成「图标没配 / 数据没下发」。项目里 5 处能正常工作的先例**全是扁平结构**。**外源 SVG 网格不同（如 1024）时，要把坐标真正算好缩放到 24 网格，而不是套 `transform`**（含 `A` 弧线时只缩放 rx/ry/x/y，不动 rot/large/sweep）。护栏 `ui-icons-shared.test.js` B3 + B4b。
- **排查「元素不显示」的第一动作：对比同项目里能正常工作的同类先例** —— 结构差异往往就是答案（本次 `grep '<g>'` 立刻暴露只有新图标一处用了 `<g>`）。**不要止步于「代码读起来是对的」**。
- **图标动效**：常驻动画只在 `.ui-icon--live` 且 `prefers-reduced-motion: reduce` 下关闭；**悬停弹动必须用 `animation` 而非 `transform`**（否则被 `press-spring` 的 `scale(0.96)` 顶掉）。同一屏常驻动画条目 ≤ 3 个。
- **页面级 vm 测试**：跨 realm 的 `deepStrictEqual` 因原型不同会失败，改用 `.length` 或 JSON 归一化；末尾 `process.exit(0)`。
- 样式 token 在 `app.wxss` 的 `page`（`--primary #315CFF`、`--bg #F4F6FA`、`--radius 18rpx`），但 `pages/about` 等页用自有一组近似硬编码色 —— **同页内改样式跟页面既有取值，别混 token**。
- 校园地图围栏：佛山 58 顶点 / 62.2 万㎡；广州新港 10 顶点 / 42.2 万㎡（护栏 `campus-map-panorama.test.js` F/G 组）。
- **docs/ 按主题合并为 14 篇，无日期命名文件**；入口 `docs/README_文档索引.md`。⚠️ 索引称旧文件「移入 `docs/_原始归档/`」，但**该目录不存在**，旧文件是被删的 —— 回溯只能 `git checkout HEAD -- docs/`。

## 抽屉 / 弹层（bottom sheet、对话框）
- **`position: fixed` 弹层必须用 `<root-portal wx:if="…">` 包裹** —— 祖先只要有 `transform`（项目的 `.spring-btn`/`.press-spring`/`:active` 全带 `transform: scale(0.96)`，页面还有 `page-enter` 动画残留）就会把 `fixed` 的包含块劫持到该祖先，弹层被**压成一条细竖列**（`contact-admin` 踩过；`pages/push-groups` 的卡片也带 `press-spring`，同样必须包）。`root-portal` 是基础组件，**页面与自定义组件里都能用**。
- **弹层内「内容可滚 + 操作栏固定底部」的标准结构**：`sheet`（`flex column` + `max-height: 82vh`）→ `<scroll-view class="…-scroll" scroll-y enable-flex>`（`flex:1; min-height:0`）→ 操作栏 **放在 scroll-view 之外**。`scroll-view` 必须有确定高度约束才会滚，靠 `flex:1`+`min-height:0` 从 sheet 的 `max-height` 里取。
- **遮罩要 `catchtouchmove="<noop>"`** —— `root-portal` 已把弹层脱离页面层级，不锁的话手指划遮罩会把背景列表一起滚走。**但不要给 sheet 本身加 `catchtouchmove`**，否则内部 scroll-view 滚不动。
- **主题色不要用 `~` 兄弟选择器从内部元素传染到外部按钮** —— hero 在滚动容器内部、与操作栏不是兄弟，`~`/`+` 命不中。**正解：按钮类名由 js 按 theme 拼出来**（`pg-btn-primary theme-{{card.theme}}`）。

## 表单：多区块共用一个字段 = 图片/数据串位
- **「A 区图片」与「B 区图片」必须各自独立数组 + 独立 handler**。反例（跑腿发布页 2026-10-06）：公开描述卡与隐私信息卡**都调 `onChooseImage`、都用 `images`**，且隐私卡只有 `add-image` 没有 `image-list` → 在隐私区传的图**既不显示、又落进公开数组**。
- 通用症状：**「收集了却不显示」+「串到了别的字段」** → 直接找「是否两个 UI 区块共用同一 `setData` 字段」。
- 新增端上字段时，**同步检查 4 处**：① `data` 初始值 ② `payload` ③ 表单指纹 `formKey`（否则复用旧订单会丢新字段）④ 上传/`_pendingOrder` 复用链路。
