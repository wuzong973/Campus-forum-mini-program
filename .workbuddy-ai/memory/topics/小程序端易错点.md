# 小程序端易错点（样式 / 图标 / 测试 / 杂项）

> 从 `MEMORY.md` 拆出（2026-10-06）。低事故区，改小程序端时读取。

- **`focus="{{x}}"` 是受控属性**，变 `true` 就聚焦拉起键盘 —— 打开只读面板（如首页评论面板）不要置 `true`。**`adjust-position="{{false}}"` 必须自己处理键盘高度**：fixed bottom 元素须绑 `bindkeyboardheightchange`（`pages/post-detail/index.wxml`）。**两个评论入口语义不同**：首页 `commentMode="sheet"`（原地开面板），其余 `"detail"`（跳详情 + `&comment=1`）。`wx.setClipboardData` 成功后微信自弹「已复制」，**不要再 showToast**。
- **矢量图标统一层 `styles/ui-icons.wxss`**：小程序 `<image>` 不能显示 `.svg`，**必须 `background-image: url("data:image/svg+xml,...")`**（`#` 转义 `%23`）。优先级 `uiIcon → fontIcon → image`；**`iconPath`（后台图片）高于 `uiIcon`**，判定必须写 `iconPath ? '' : (def.uiIcon || '')`，**首页宫格与个人中心两处都要**。
- **⚠ 内联 SVG 必须是「`<svg>` 直接包 `<path>`」的扁平结构，禁用 `<g>` / `transform`**（2026-10-06 实机踩坑）—— 微信 WXSS 的 `background-image` 对内联 SVG 解析不如浏览器宽容，`<g>` / `transform=` 会让**整张图静默渲染失败**（格子空白、**控制台无任何报错**），极易误判成「图标没配 / 数据没下发」。项目里 5 处能正常工作的先例**全是扁平结构**。**外源 SVG 网格不同（如 1024）时，要把坐标真正算好缩放到 24 网格，而不是套 `transform`**（含 `A` 弧线时只缩放 rx/ry/x/y，不动 rot/large/sweep）。护栏 `ui-icons-shared.test.js` B3 + B4b。
- **排查「元素不显示」的第一动作：对比同项目里能正常工作的同类先例** —— 结构差异往往就是答案（本次 `grep '<g>'` 立刻暴露只有新图标一处用了 `<g>`）。**不要止步于「代码读起来是对的」**。
- **图标动效**：常驻动画只在 `.ui-icon--live` 且 `prefers-reduced-motion: reduce` 下关闭；**悬停弹动必须用 `animation` 而非 `transform`**（否则被 `press-spring` 的 `scale(0.96)` 顶掉）。同一屏常驻动画条目 ≤ 3 个。
- **页面级 vm 测试**：跨 realm 的 `deepStrictEqual` 因原型不同会失败，改用 `.length` 或 JSON 归一化；末尾 `process.exit(0)`。
- 样式 token 在 `app.wxss` 的 `page`（`--primary #315CFF`、`--bg #F4F6FA`、`--radius 18rpx`），但 `pages/about` 等页用自有一组近似硬编码色 —— **同页内改样式跟页面既有取值，别混 token**。
- 校园地图围栏：佛山 58 顶点 / 62.2 万㎡；广州新港 10 顶点 / 42.2 万㎡（护栏 `campus-map-panorama.test.js` F/G 组）。
- **docs/ 按主题合并为 14 篇，无日期命名文件**；入口 `docs/README_文档索引.md`。⚠️ 索引称旧文件「移入 `docs/_原始归档/`」，但**该目录不存在**，旧文件是被删的 —— 回溯只能 `git checkout HEAD -- docs/`。

## 抽屉 / 弹层（bottom sheet、对话框）
- **`position: fixed` 弹层必须用 `<root-portal wx:if="…">` 包裹** —— 祖先只要有 `transform`（项目的 `.spring-btn`/`.press-spring`/`:active` 全带 `transform: scale(0.96)`，页面还有 `page-enter` 动画残留）就会把 `fixed` 的包含块劫持到该祖先，弹层被**压成一条细竖列**（`contact-admin` 踩过；`pages/push-groups` 的卡片也带 `press-spring`，同样必须包）。`root-portal` 是基础组件，**页面与自定义组件里都能用**。
- **弹层内「内容可滚 + 操作栏固定底部」的标准结构**：`sheet`（`flex column` + `max-height: 82vh`）→ `<scroll-view class="…-scroll" scroll-y enable-flex>`（`flex:1; min-height:0`）→ 操作栏 **放在 scroll-view 之外**。`scroll-view` 必须有确定高度约束才会滚，靠 `flex:1`+`min-height:0` 从 sheet 的 `max-height` 里取。
- **遮罩要 `catchtouchmove="<noop>"`** —— `root-portal` 已把弹层脱离页面层级，不锁的话手指划遮罩会把背景列表一起滚走。**但不要给 sheet 本身加 `catchtouchmove`**，否则内部 scroll-view 滚不动。
- **主题色不要用 `~` 兄弟选择器从内部元素传染到外部按钮** —— hero 在滚动容器内部、与操作栏不是兄弟，`~`/`+` 命不中。**正解：按钮类名由 js 按 theme 拼出来**（`pg-btn-primary theme-{{card.theme}}`）。

## 表单：多区块共用一个字段 = 图片/数据串位
- **「A 区图片」与「B 区图片」必须各自独立数组 + 独立 handler**。反例（跑腿发布页 2026-10-06）：公开描述卡与隐私信息卡**都调 `onChooseImage`、都用 `images`**，且隐私卡只有 `add-image` 没有 `image-list` → 在隐私区传的图**既不显示、又落进公开数组**。
- 通用症状：**「收集了却不显示」+「串到了别的字段」** → 直接找「是否两个 UI 区块共用同一 `setData` 字段」。
- 新增端上字段时，**同步检查 4 处**：① `data` 初始值 ② `payload` ③ 表单指纹 `formKey`（否则复用旧订单会丢新字段）④ 上传/`_pendingOrder` 复用链路。

## ⚠ 站内路径：分包前缀 + tabBar 必须 switchTab（2026-10-08）
- **本项目 35 个页面在 `pkg-feature` 分包**（另有 `pkg-user` / `pkg-schedule` / `pkg-admin`），
  真实路径是 **`/pkg-feature/pages/xxx`，不是 `/pages/xxx`**。写「以 `/pages/` 开头就跳转」
  这类判据会把**分包页面全部漏判** —— 表现为「点了完全没反应」或「链接被复制到剪贴板」，
  **不报错**。
- **站内跳转一律走 `utils/link.js`**（唯一入口，勿再各处自写）：
  `isInnerPath` / `isWebUrl` / `isTabBarPage` / `openPath(url,{fail})`。
  `openPath`：tabBar → `switchTab`（**必须剥掉 query**，switchTab 不接受参数）；
  其他站内 → `navigateTo`；非站内返回 `false` 交调用方兜底（复制/提示）。
  **顶层不得引用 `wx`/`getApp`**，否则 `server/tests` 的 Node 单测 require 不了。
- **tabBar 页面只能用 `switchTab`**，`navigateTo` 对它**直接报错**。tabBar 列表在
  `utils/link.js` 里硬编码，由护栏逐项对齐 `app.json`（**加/删 tab 必须同步**）。
- **⚠ 别用子串猜目标页**（`indexOf('index') > -1` 就跳首页）：分包路径里几乎都含
  `index`，会把**正确路径误跳回首页**。历史 `onBannerTap` 就是这个写法。
- 服务端链接校验正则同样要放行分包：`PAGE_LINK_RE = /^\/(?:pages|pkg-[A-Za-z0-9_-]+)\/|^https?:\/\//i`
  （`configController.js` 顶部，全局只定义一次）。**只写 `/pages/` 会让管理员在后台填分包路径时被挡在保存前。**
- 护栏 `server/tests/miniprogram-link-routing.test.js`（A tabBar 对齐 app.json /
  B 分包判定 + 拒绝 `javascript:` `data:` / C 消费端不得再自写 `indexOf('/pages/')` /
  D 服务端正则唯一且同口径）。

## ⚠ `#小程序://` 短链不能当跳转目标（2026-10-08）
- **`#小程序://<名称>/<短码>` 是微信「小程序短链」，只能粘进微信聊天里点开**
  （服务端 `services/groupBroadcastService.js` 的群发靠它，`group-broadcast.test.js`
  明确要求「保持原文不改写，改写后聊天里点不开」）。
  **小程序内部没有任何 API 能用它跳转** —— 它不是页面路径，`wx.navigateTo` 用不了。
- 症状：管理员把它填进轮播/自定义页的「跳转路径」，保存时不报错，用户点了只弹
  **「链接已复制」**（复制兜底）。**排查先看库里存的是什么**（只读探针），别先怀疑代码。
- 正确填法：**页面路径**，注意分包前缀 `/pkg-feature/pages/xxx`。
- 校验统一在 `utils/link.js`（端上）与 `server/utils/link.js`（服务端）：
  `isNavigableLink` / `linkRejectReason`。**两个运行时没法共用文件，靠
  `miniprogram-link-routing.test.js` 的同一张用例表守住一致性。**

## ⚠ 小程序页面路径不带文件后缀（2026-10-08）
- **`/pkg-feature/pages/activity/index` ✔** ／ **`/pkg-feature/pages/activity/index.html` ✘**
  `.html` 是网页习惯；小程序里带后缀的路径不是注册页面，`navigateTo` 直接失败，
  用户只看到一句「该页面暂不可用」。**前缀对、后缀错最难自查**（管理员会觉得"按提示填了"）。
- 校验规则（`utils/link.js` / `server/utils/link.js` 同源）：
  只对**站内路径**查后缀，且只查**剥掉 query/hash 后的路径**——
  `/pages/a/index?x=1.html` 要放行，`https://a.com/page.html` 也要放行（**外链带 .html 很正常**）。
- **`isNavigableLink(url)` 必须实现成 `!linkRejectReason(url)`**，让「判定」与「原因」同源；
  各写一套迟早分叉（本次就是这么漏掉后缀检查的）。

## 后台配「跳转路径」：选页面优先，别再让人手打（2026-10-08）
- **可跳转页面清单在 `utils/page-list.js`**（8 个分组 / 57 个可选页 + 18 个带理由的排除项）。
  **不变量：清单 ∪ 排除表 == `app.json` 全部页面** —— 新增页面必须补进其中之一，
  否则后台永远选不到它，且**静默**。护栏 `tests/miniprogram-page-list.test.js` A 段。
- 判断「某页能否无参打开」**用行为判据**（扫 `onLoad` 里有没有「缺参数就 return」的守卫），
  **别按文件名猜** —— `/(detail|target)$/` 会把 `/pkg-feature/pages/club/detail` 误判
  （它其实用 `options.id || ''` 兜底、无参能开）。
- **各分包内层结构不一致**，补前缀**不能拼**：`pkg-feature` 带 `pages/`、
  **`pkg-schedule` 不带**（`/pkg-schedule/schedule-home/index`）、`pkg-user` 带。
  正解是按清单建「尾巴索引」再还原，且**只在唯一匹配时改**。
- `normalizePagePath` 的 4 条纠错顺序有讲究：**先补斜杠再判后缀**，
  否则 `INNER_PATH_RE` 匹配不上 `pkg-feature/pages/x/index.html`。
  纠错**只对站内路径**：外链以 `.html` 结尾是正常的，误伤就是新 bug（用例表里有反向保护）。
- **搜索结果列表项必须用 `data-path` / `data-id` 传值，不能用 `data-index`** ——
  列表是过滤后的，拿下标回查原清单必然错位。**搜索还要按命中位置排序**：
  分组名往往包含关键词（搜「活动」命中分组「社团与活动」），不排序会把精确匹配压到后面。
- **详情页路径要 id 时，别让运营手填**：复用现成的 `admin.posts({keyword})` 做「选帖子」，
  选中后 `postDetailPath(id)` 拼路径。`postDetailPath` 只接受正整数（否则拼出 `?id=NaN`）。
- **论坛帖的主字段是 `content`，不是 `title`** —— `forum_post` 实测 353 行里 **352 行 `title` 为空**。
  任何展示帖子列表的地方都要用 `format.postTitle(row)`（title 优先、空则截正文摘要），
  **只读 `row.title` 会满屏「（无标题）」**。后台列表页 `pkg-admin/admin/index.wxml` 渲染的也是 `content`。
- **兜底类代码的用例必须传 `null` / `undefined` 本身**：`x || {}`、`String(x || '')` 这类兜底，
  只测「对象里字段为空」测不到「对象本身为空」——反向验证实测漏网过。
- **跳转路径配置统一走 `components/link-picker`**（选页面 / 选帖子 / 手动输入）。
  新增跳转配置点时**直接用这个组件**，别再写裸 input —— 各写一份必然分叉。
- **⚠ 组件必须放主包 `components/`**：`pkg-admin` 与 `pkg-feature` 都要用它，
  而**分包之间不能互相引用**（只能引主包）。同理**主包组件/工具不得 require 分包文件**
  （`pkg-admin/utils/admin.js` 引不到 → 真机 module not found），
  要用接口就自己 `require('utils/request')`。护栏 `miniprogram-page-list.test.js` 有这两条。
- **⚠ 服务项的「H5 链接」不能用跳转选择器**：`pages/index/index.js` 的 `onServiceTap`
  对非 `http(s)` 的 link 直接提示「该服务链接暂不可用」——**页面路径在那里走不通**。
- **组件里输入框要绑本地值而不是 property**：绑 property 会「输入 → emit → 宿主 setData
  → observer 回写」，**光标被顶到末尾**。
