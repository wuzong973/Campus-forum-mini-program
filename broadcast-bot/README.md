# 微信群播报机器人 · 交付使用说明

把每 20 分钟生成的「论坛广播」文案（新帖摘要 + 可点开的小程序短链）**自动发送到微信群**，
代替人工复制粘贴。原理：一台 Windows 电脑上跑一个小程序，轮询服务器拿待发文案，
在「企业微信 PC 客户端」里模拟人的操作搜索群、粘贴、发送。不注入协议、不接第三方，安全风险最低。

## 一、交付包里有什么

| 文件 | 作用 |
|---|---|
| `1-安装环境.cmd` | **双击一次即可**：自动下载并安装独立 Python（装在本文件夹 `runtime\` 内，不修改系统、不需要管理员权限），并安装两个组件 |

## 二、首次配置（三步，约 10 分钟）

**第 0 步 · 两个前提**：

- ⚠️ **必须先把压缩包完整解压到一个固定文件夹（比如桌面）再运行**，不要在压缩包/微信预览里直接双击脚本；
- 这台电脑要常年开机，且已用「广轻观察」这个企业微信账号登录**企业微信 PC 客户端**（保持主窗口打开，可最小化，不要退出登录）。

1. **双击 `1-安装环境.cmd`**，等它自己下载安装完成（需联网，全程 2~5 分钟，显示「Setup done」即可）。
   脚本每次运行都会重建一个干净的独立 Python 环境（装在本文件夹 `runtime\` 内，不碰系统、不需要管理员），
   之前装坏了也没关系，直接重跑就会自动重置；
2. **核对 `config.ini`**：
   - `names =` 已预填验收群「广轻工校内论坛群1️⃣」——就是这个 4 人的群，**首次验收直接用它**；
   - 验收通过后再把正式的大群群名补进去（多个用英文逗号隔开）；
   - `bot_token` 已预填好，**不要改**（和服务器配对的密钥）；
3. **双击 `2-启动播报机器人.cmd`**，窗口出现「论坛播报机器人启动」即在工作。

> 服务器每 20 分钟聚合一次新帖：有新帖才会生成文案，没有新帖不发（窗口里显示「暂无待发播报」属正常）。
> 机器人领取到文案后会在窗口和 `logs\bot.log` 里逐群显示发送结果。
> 群名里的表情如果搜索匹配不上：在企微搜索框搜这个群，把搜索结果里的完整群名（含表情）复制进 config.ini。

## 三、验收清单

- [ ] 「广轻工校内论坛群1️⃣」收到完整文案：几条帖子 + `#小程序://…` 蓝色短链（点开直达帖子）；
- [ ] 分隔线下方是「考驾校就选【驾顺驾校】」短链和「最新投稿广轻工论坛入口」；
- [ ] 同一条文案没有重复发（服务端有防重锁）；
- [ ] 验收通过后：把 `config.ini` 的 `names` 换成/补上正式群名，重启机器人（关窗再双击启动）；
- [ ] 需要无人值守：双击 `3-开机自启.cmd`。

## 四、常见问题

> **安装失败怎么办（重要）**：安装脚本用的是「绿色便携版 Python」（免安装、直接解压、不写注册表），
> **每次运行都会自动重建干净环境**，之前装坏过也无需处理，直接重跑即可。
> 标准安装器路径已弃用，因此杀毒拦截安装器、系统缺组件、注册表残留等问题都不会再出现。
> 如果仍然失败，把包里的 `bot-setup.log` 发给技术对接人。
> ⚠️ 另外请确认是**解压后**运行：在压缩包/微信预览里直接双击脚本会导致文件散落在临时目录。

| 日志显示「ok」但群里没收到 | 三个最常见原因，按顺序查：① 打开甲方电脑上的企微，在搜索框手动搜目标群名——**搜不到 = 广轻观察这个号不在群里**，先把它拉进群；② 能搜到的话手动点开群、手动发条消息确认通路；③ 把 `logs\` 里时间对应的 `search_*.png / opened_*.png / pasted_*.png / sent_*.png` 截图发给技术对接人（排查期间企微窗口不要最小化，否则截图是黑的） |
| 文案进了输入框但没发出去 | 检查企微「设置 → 通用 → 按 Enter 键发送消息」是否开启；若设置了 Ctrl+Enter 发送，新版机器人会自动换键重试并校验输入框清空，升级到最新包即可 |
| 报「The folder is INCOMPLETE / Missing files」 | 文件夹不完整：说明压缩包没有完整解压或文件被移走，重新解压完整 zip 到一个文件夹再运行 |
| 报「Could not open requirements file」 | 同上（旧版脚本才会出现）；新版脚本已内置清单，换新版包即可 |
| 安装卡在下载 | 网络问题，换个网络重试；或让技术对接人换安装包源 |
| 杀毒软件/360 弹窗拦截 | 允许运行，把本文件夹加入白名单 |
| 「未找到企业微信主窗口」 | 企微主窗口要开着（可最小化到任务栏，不能只挂托盘图标），确认登录的是「广轻观察」 |
| 窗口报轮询异常 invalid bot token | `config.ini` 里的 bot_token 被改动了，找技术对接人拿正确值 |
| 搜索后没打开目标群 | 打开 `config.ini` 调大 `search_wait`（比如 4.0）；仍不行看下一条 |
| 群名写了但没发出去 | 群名必须和企微搜索框里显示的完全一致（含表情和符号），建议从企微搜索里复制 |
| 发出去没有换行/格式乱 | 确认没动 `broadcast_bot.py`；截图 `logs\bot.log` 找技术对接人 |
| 同一条发两次 | 服务端有 5 分钟抢占锁，重复一般因为机器人被启动了两份——只保留一个窗口 |
| 电脑重启后机器人没跑 | 双击 `2-启动播报机器人.cmd` 手动跑；或之前设置过 `3-开机自启.cmd` 检查任务计划程序 |
| 想临时停止 | 关闭机器人窗口即可（自启版：双击 `4-取消开机自启.cmd`） |

## 五、运营注意

- **机器人上线后，不要再手动把企微推送里的文案复制进群**（会重复发）。企微「推送」应用里的文案仅当存档/查看；
- 要调整播报频率、条数、页脚广告，联系技术对接人改服务器配置（当前：20 分钟一轮，每轮最多 6 条新帖）；
- 短链有效期由服务器自动续期，无需人工维护。
