# 微信小程序 UGC 合规检查清单

## 已修复

- 帖子、评论、回复、转发、私信、跑腿、评价、反馈和资料编辑统一经过服务端内容安全中间件。
- 文本检测调用 `wxa/msg_sec_check` 2.0，携带 `version=2`、用户 `openid`、业务 `scene`，并处理 `87014` 与 `result.suggest`。
- 生产环境未配置内容安全服务或微信接口不可用时，提交会被拒绝，不会绕过审核写入数据库。
- 用户公共图片上传在返回 URL 前调用 `wxa/img_sec_check`；命中违规或检测失败会删除临时文件。
- 帖子标题、正文、评论和私信增加长度上限，避免超过接口或数据库约束。

## 发布前必须在微信后台核对

1. `WX_APPID`、`WX_APPSECRET` 与线上小程序一致，服务端不得使用示例值。
2. 将生产 API 域名加入 request 合法域名，将上传/媒体域名加入 download/upload 合法域名，并全程使用 HTTPS。
3. 在微信公众平台完成用户隐私保护指引，发布前在小程序隐私协议中说明头像、昵称、手机号、图片和内容审核用途。
4. 内容安全接口调用主体必须是服务端；不要在小程序端保存 `appSecret` 或直接调用微信开放接口。
5. 配置违规内容处理、用户投诉和管理员审核流程，保留审核失败原因与必要的审计日志。
6. 图片、视频等媒体发布前必须完成对应的图片/媒体安全检测；当前上传接口已覆盖图片，视频发布仍需接入 `media_check_async` 后再开放生产开关。

## 参考官方接口

- 文本内容安全：`https://developers.weixin.qq.com/miniprogram/dev/api-backend/open-api/sec-check/security.msgSecCheck.html`
- 图片内容安全：`https://developers.weixin.qq.com/miniprogram/dev/api-backend/open-api/sec-check/security.imgSecCheck.html`
- 媒体内容安全：`https://developers.weixin.qq.com/miniprogram/dev/api-backend/open-api/sec-check/security.mediaCheckAsync.html`
