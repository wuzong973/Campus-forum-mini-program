# 质量优化修复说明

## 1. 数据一致性

- 维修预约费统一为服务端真实金额 `19.90` 元，修复页面显示与帮助文案不一致。
- 新增 `POST /api/v1/schedule/replace`，由服务端事务性替换用户课表。
- 课表单条新增接口增加星期、周次、单双周和文本长度校验。

## 2. 真实数据治理

- 删除前端 Mock 评论数组、Mock 评论缓存和相关状态变量。
- 删除服务端开发模拟登录路由及控制器。
- 删除发布页本地默认横幅，发布横幅只从服务端配置读取。
- 删除维修页本地维修人员兜底，避免展示无法预约的过期人员。
- OCR 无有效识别结果时直接返回 422，不再返回演示课程。

## 3. 交互稳定性

- OCR 导入失败时保留原课表，不再出现“提示成功但后端只写入部分课程”的状态。
- OCR 导入请求增加幂等键，重复点击不会创建重复批量操作。
- 教务系统链接切换为 HTTPS，避免 WebView 被平台安全策略拦截。

## 4. 验证结果

- 后端现有测试：通过。
- 前端 JavaScript 语法检查：通过。
- 页面注册文件检查：通过。
- 真机和微信开发者工具运行时验证：当前环境未提供，需发布前完成。
