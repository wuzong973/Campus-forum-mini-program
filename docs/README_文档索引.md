# 文档索引 · 校园论坛小程序

> 整理日期：2026-09-16
> 背景：`docs/` 目录曾累积 76 篇 Markdown，多为按日期命名的「修复说明 / 功能说明 / 排查报告」，同一问题在多篇里反复出现。
> 处理方式：按主题合并为 **14 篇**结构化的文档（见下），75 篇原始文件整体移入 `docs/_原始归档/`，内容未删改，可随时对照回溯。
> 合并原则：同一问题的多处描述只保留最终结论；多篇结论冲突时以日期最新的为准，并在正文中标注「以 YYYY-MM-DD 文档为准」；相对时间（"今天""本次"）已改写为绝对日期。
>
> **整理后新增：** 2026-09-16 的「授权弹窗触发点扩展」按同一原则并入 [订阅消息_功能实现与改造.md](./订阅消息_功能实现与改造.md) §六，未新建按日期命名的文件。
> 2026-09-19 管理后台日志 tab 新增「维修信息」入口，并入 [管理后台运维与发布合规.md](./管理后台运维与发布合规.md) §1.8，维修模块侧同步补在 [校园服务与评价模块.md](./校园服务与评价模块.md) §四。
