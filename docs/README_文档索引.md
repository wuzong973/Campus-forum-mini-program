## 四、文档维护约定（重要）

1. **不再新建按日期命名的文档**。新改动请并入上表 6 篇中对应功能域的那一篇。
2. **同一功能的改动说明必须写进该功能的章节**，不要新开顶层章节；修复记录作为该章节的子节，排在「遗留问题」之前。
3. **跨域主题只在一处展开**，其他位置用链接或一句话指路，并在该篇的「阅读指引」表里登记。
4. **结论冲突以日期最新的为准**，并在正文标注「以 YYYY-MM-DD 文档为准」。
5. **相对时间一律写绝对日期**（"今天" → "2026-10-07"）。
6. 新增文档时，同步更新本索引的「合并后的文档」表。
