# 校园论坛小程序代码审查与质量优化方案

审查日期：2026-09-08

## 一、需求总结

本次工作目标是对微信小程序、Node.js 服务端、MySQL 数据层和教务同步链路进行一次完整的工程质量审查，并将发现的问题直接修复。审查重点包括：

1. 前后端接口、请求参数、响应字段和数据库字段必须保持可追踪的一致性。
2. 页面跳转、组件交互、请求并发、缓存更新和长列表滚动不能出现重复操作、状态错乱或明显延迟。
3. 生产包不得展示或写入测试用户、模拟帖子、虚拟评论、演示课程和开发登录数据。
4. 个人数据必须由服务端作为权威来源，本地缓存只能用于加速读取或保存可重放的离线设置。
5. 课程导入、支付、订单、消息等跨页面链路必须在失败时保持可恢复，不能提示成功但只写入部分数据。
6. 文字、图标、间距、按钮状态和空状态需要在小屏、常用手机宽度和不同数据量下保持稳定。
7. 与小程序业务无关的诊断、演示和历史遗留文件应从正式代码路径中隔离或删除，不能进入发布包。

## 二、扩展后的可执行指令

### 数据链路

- 逐一登记前端调用、服务端路由、控制器、数据库表和返回字段。
- 对所有分页接口验证 `page`、`pageSize`、`total`、`hasMore` 的含义一致。
- 对同一业务同时存在的 snake_case/camelCase 字段统一在边界层转换。
- 写操作默认不自动重试；需要重放的资料和配置写入必须带幂等键。
- 任何本地缓存都必须有明确的 key、写入时机、失效时机和失败回源策略。

### 交互与状态

- 所有提交、支付、点赞、导入、加载更多操作都必须具备防重复提交状态。
- 页面离开或返回时，清理定时器、加载状态和临时弹层状态。
- 异步操作失败时必须恢复按钮、输入框和页面状态，并给出可理解的错误信息。
- 长列表使用分页、懒加载和节流；不得在滚动事件中高频无条件 `setData`。

### 真实数据治理

- 删除 Mock 数据、seed 演示数据、虚拟默认评论、演示课程和开发登录入口。
- 真实业务配置可以保留，但应以服务端为唯一来源，接口失败时显示空状态或失败状态。
- 测试用例中的 mock 只允许存在于测试文件，不得被业务运行时代码引用。

### 视觉与兼容性

- 页面使用统一的字号、颜色、圆角、边距和状态色变量。
- 所有图标使用同一资源体系，避免文字符号与图片图标混用造成风格不一致。
- 固定格式的课表、列表、按钮和输入区域使用稳定尺寸，防止异步内容造成布局跳动。
- 必须覆盖空数据、超长文本、弱网失败、重复点击和不同屏幕宽度场景。

## 三、本次审查结论

### 已确认并修复

| 优先级 | 问题 | 修复 |
| --- | --- | --- |
| P0 | OCR 无结果时在开发环境返回三门演示课程 | 统一改为明确失败，不产生虚假课程 |
| P0 | 前端维修金额为 0.99，服务端实际收款为 19.90 | 前端展示和帮助文案统一为 19.90 |
| P1 | OCR 导入先清空再逐条写入，失败被吞掉 | 新增 `/schedule/replace` 事务接口，整表成功或原数据保持不变 |
| P1 | `utils/api.js` 残留 Mock 评论和本地虚拟评论缓存 | 完整删除运行时 Mock 逻辑 |
| P1 | 服务端存在开发模拟登录接口 | 删除 `/user/dev-login` 及实现 |
| P1 | 维修人员接口失败时使用本地人员名单 | 改为只使用服务端返回的可预约人员 |
| P1 | 教务系统入口使用 HTTP | 改为 HTTPS |
| P2 | 课表单条新增参数缺少边界校验 | 增加星期、周次、文本长度和单双周校验 |

### 未能在当前环境完成的验证

- 微信开发者工具真实编译和 WXML/WXSS 运行时渲染。
- 真机页面转场、键盘、安全区域和滚动性能。
- 生产 MySQL、Redis、微信登录、微信支付、对象存储和教务系统真实联调。
- 真 OCR 引擎输出质量和教务系统账号登录成功率。

这些项目不能用本地语法检查代替，发布前必须按 `docs/RELEASE_CHECKLIST.md` 完成验收。

## 四、回归测试清单

- 后端：`cd server && npm test`
- 前端 JavaScript：逐文件 `node --check`
- 页面注册：校验 `app.json` 与子包页面文件完整性
- 课程导入：确认批量写入失败时旧课表仍存在，成功时整表替换
- OCR：无真实识别结果时不得出现课程对象
- 真实数据扫描：业务代码不得再引用 `MOCK_*`、`mock_comments`、`dev-login` 或 `demo-fallback`
- 发布包：确认 `server`、`jw-crawler`、文档、测试种子和本地配置不会进入小程序包
