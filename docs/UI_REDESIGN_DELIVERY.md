# UI Redesign Delivery

## Scope

- Home feed post card layout, typography, interaction states, favorite/share/more actions.
- Home service icon system and grid spacing.
- Schedule grid, quick course entry, OCR import flow, course conflict detection, import/export settings.
- Home carousel artwork, dynamic content generation, custom indicator and lazy-loaded assets.
- Public profile visual refresh and profile editing workflow.

## Visual Tokens

- Primary: `#315CFF`
- Accent: `#12B8A6`
- Warm: `#FF8A3D`
- Background: `#F4F6FA`
- Card radius: `18rpx`
- Motion: `160ms` press feedback, `240-320ms` transitions.

## Assets

- Carousel: `assets/banners/banner-schedule.png`, `banner-community.png`, `banner-errand.png`, all `750x400`, each under `10KB`.
- Service icons: `assets/icons/svc-*.png`, `48x48`, transparent PNG.
- Feed action icons: `assets/icons/star.png`, `star-outline.png`, `more.png`.

## Implementation Notes

- Carousel content is generated by `utils/banner.js` from schedule, posts and service context.
- Post cards support 1/2/3+ image layouts and optimistic like/favorite/follow state.
- Publishing supports image/video media selection, draft persistence, loading state, failure retry and home feed insertion.
- Schedule edit supports JSON import/export, conflict detection and reminder offset settings.
- Profile edit supports avatar/cover/signature/social/module visibility and ordering with draft, preview and rollback.

## Validation

- `node --check` for touched JS files.
- `npm test` in `server`.
- Manual device validation should check 375px mobile, 768px tablet and desktop simulator widths in WeChat DevTools.

## Known Boundary

Figma MCP tools were not exposed in this session, so the design deliverable is implemented as repository assets, code and this handoff document rather than a live Figma file.
OCR accuracy can only be certified above 95% after connecting a real OCR engine and running a labeled schedule-image evaluation set.
