# UI 重设计交付

## 范围

- 首页信息流帖子卡片布局、排版、交互状态、收藏/分享/更多操作。
- 首页服务图标系统和宫格间距。
- 课表网格、快速添加课程入口、OCR 导入流程、课程冲突检测、导入/导出设置。
- 首页轮播图素材、动态内容生成、自定义指示器和懒加载资源。
- 公开个人资料视觉刷新和个人资料编辑工作流。

## 视觉令牌

- 主色：`#315CFF`
- 强调色：`#12B8A6`
- 暖色：`#FF8A3D`
- 背景色：`#F4F6FA`
- 卡片圆角：`18rpx`
- 动效：`160ms` 按下反馈，`240-320ms` 过渡动画。

## 资源

- 轮播图：`assets/banners/banner-schedule.png`、`banner-community.png`、`banner-errand.png`，尺寸均为 `750x400`，每张不超过 `10KB`。
- 服务图标：`assets/icons/svc-*.png`，`48x48`，透明 PNG。
- 信息流操作图标：`assets/icons/star.png`、`star-outline.png`、`more.png`。

## 实现说明

- 轮播图内容由 `utils/banner.js` 根据课表、帖子和服务上下文动态生成。
- 帖子卡片支持 1/2/3+ 图片布局以及乐观更新的点赞/收藏/关注状态。
- 发布支持图片/视频媒体选择、草稿持久化、加载状态、失败重试和首页信息流插入。
- 课表编辑支持 JSON 导入/导出、冲突检测和提醒偏移设置。
- 个人资料编辑支持头像/封面/签名/社交/模块可见性和排序，并提供草稿、预览和回滚功能。

## 验证

- 对修改过的 JS 文件运行 `node --check`。
- 在 `server` 中运行 `npm test`。
- 手动设备验证应在微信开发者工具中检查 375px 手机、768px 平板和桌面模拟器宽度。
