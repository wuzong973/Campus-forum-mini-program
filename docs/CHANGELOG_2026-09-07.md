# 2026-09-07 更新说明

## 版本范围

本次更新针对校园论坛微信小程序的跑腿模块、聊天页面视觉样式和后端全量部署流程。代码仍采用单仓库结构：小程序前端位于仓库根目录，Node.js 服务端位于 `server/`，教务系统相关代码位于 `jw-crawler/`。

## 功能与界面变更

### 跑腿大厅

- 跑腿大厅背景调整为与首页一致的浅蓝渐变和径向高光，改善页面之间的视觉连续性。
- 顶部导航栏增加微信小程序原生导航栏颜色配置，文字改为深色，保证浅色背景下的可读性。
- 公告栏改为由 `showNoticeA`、`showNoticeB` 两个开关驱动的公告列表。
- 用户关闭公告后，页面会立即重建公告列表，关闭状态只影响当前页面显示，不会错误地保留已关闭公告的占位。
- 两条公告分别用于提示平台支付安全和接单后的及时沟通、订单确认。

### 发布跑腿

- 发布页导航栏同步使用浅蓝色背景和深色文字。
- 页面顶部背景渐变与首页、跑腿大厅统一，保留原有表单、图片和金额校验逻辑。

### 聊天页面

- 自定义导航栏改用首页同款浅蓝渐变。
- 返回图标、返回帖子按钮改为深色文字与半透明浅色按钮，提升浅色导航栏上的对比度。
- 返回按钮悬停态改为更明显的浅色背景反馈。

## 部署脚本变更

`deploy_full.py` 用于将后端核心文件上传到服务器并重启 PM2 服务。本次同步包含以下安全调整：

- 不再在源码中保存服务器密码。
- 服务器地址、用户名、密码、远端目录均支持环境变量配置。
- `LOCAL_BASE` 改为根据脚本所在目录计算，不依赖固定的本机盘符。
- 未提供 `DEPLOY_PASSWORD` 时，脚本会在连接服务器前停止并返回失败状态。
- 部署日志仍写入本地 `.workbuddy/deploy_log.txt`，该目录不应提交到仓库。

## 部署前配置

PowerShell 示例：

```powershell
$env:DEPLOY_SERVER = "your.server.host"
$env:DEPLOY_USER = "root"
$env:DEPLOY_PASSWORD = "在当前终端临时设置的密码"
$env:DEPLOY_REMOTE_BASE = "/home/springboot/server"
python .\deploy_full.py
```

可选变量及默认值：

| 变量                 | 默认值                    | 说明             |
| -------------------- | ------------------------- | ---------------- |
| `DEPLOY_SERVER`      | `193.112.187.95`          | SSH 服务器地址   |
| `DEPLOY_USER`        | `root`                    | SSH 用户名       |
| `DEPLOY_PASSWORD`    | 无                        | 必填，不写入代码 |
| `DEPLOY_REMOTE_BASE` | `/home/springboot/server` | 服务端部署目录   |

部署脚本依赖 `paramiko`。如果当前 Python 环境未安装，请先执行：

```powershell
python -m pip install paramiko
```

脚本会依次执行以下操作：

1. 检查待上传的后端核心文件是否齐全。
2. 通过 SFTP 上传控制器、路由、工具类和服务端入口文件。
3. 在远端执行生产依赖安装。
4. 重启 `GQG-campus` PM2 进程；若该进程不存在则尝试重启全部 PM2 进程。
5. 输出 PM2 状态和最近日志，并将结果保存到本地部署日志。

## 验证清单

### 静态检查

```powershell
python -m py_compile .\deploy_full.py
node --check .\pages\errand\index.js
```

微信开发者工具中还应检查：

- `pages/errand/index.json` 和 `pages/errand-publish/index.json` 可正常解析。
- 跑腿大厅可以分别关闭两条公告，列表不会出现空白项。
- 发布跑腿页、聊天页导航栏文字和返回控件在浅色背景下清晰可见。

### 部署后检查

- 通过 PM2 确认目标服务处于 `online` 状态。
- 查看服务端最近日志，确认无启动异常。
- 在小程序中至少验证登录、跑腿大厅加载、发布跑腿和聊天返回流程。

## 安全注意事项

- 不要把 `DEPLOY_PASSWORD` 写入脚本、`.env`、日志或 Git 提交。
- 不要提交 `.workbuddy/`、`.env`、私钥、验证码图片和爬虫调试产物。
- 如果历史提交中曾暴露过真实密码，应立即更换服务器密码，并清理远端凭据访问权限。
